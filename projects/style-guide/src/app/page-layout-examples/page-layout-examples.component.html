Page layout examples

Important information regarding forms

All form elements must be nested inside a div with the class .field, if there is too much margin (usually on the first field in the group), please add the additional class .boxed. This also applies to the first H2 on the page.

Nested inside this div and in the following order, you should have a label, input and any validation message. The validation div is triggered by the class name .error appended to the wrapping field div and an additional *ngIf added to the error message div itself. The Basic vertical form below includes common form markup and example validation
