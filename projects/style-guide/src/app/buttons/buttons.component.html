Custom button

In curtain circumstances, if an existing button is not available you
might want to create your own. To do this use the below tool to preview
one of the Material Icons and then choose your background colour.
If you do not want to display the button label, add .label-transparent to the parent div.field element. DO NOT remove the label as this maintains the vertical alignment when alongside other form elements

Icon buttons

If you want a button with just an icon and no text, you can simply use a button with the .material-icons class and the icon friendly name, also remember to include the relevant button class, .primary, .secondary etc.
If you do not want to display the button label, add .label-transparent to the parent div.field element. DO NOT remove the label as this maintains the vertical alignment when alongside other form elements

Standard buttons

There is an array of standard buttons available in
Design Language. For consistency, please try and use the
standard versions wherever possible.
If you do not want to display the button label, add .label-transparent to the parent div.field element. DO NOT remove the label as this maintains the vertical alignment when alongside other form elements
