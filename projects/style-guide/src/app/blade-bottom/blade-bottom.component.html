Blade bottom

To get pinning to work, you must add the following to the page content-container
[ngStyle]="isPinned && isOpen {‘'height' : 'calc(50vh - 7.5rem)', 'overflow-y' : 'scroll'}"

These setting are adjustable.

Attributes
Element Attribute Type Default
ph-blade-bottom [isOpen] Function Your logic
ph-blade-bottom fullScreenPos Any 7.25rem
ph-blade-bottom unpinnedOffset Any Only set a value, i.e. '4.25rem' if you're using the page footer
ph-blade-bottom [zIndex] Number 1
ph-blade-bottom (bladePinned) Event bladeIsPinned($event)
ph-blade-bottom (bladeOpen) Event bladeIsClosed($event)
