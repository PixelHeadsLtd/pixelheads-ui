Blade bottom

To get pinning to work, you must add the following to the page content-container
[ngStyle]="isPinned && {‘'height' : 'calc(50vh - 10.5rem)', 'overflow-y' : 'scroll'}"

These setting are adjustable.

For ag-grid scrolling to fill height, you must set domLayout to 'normal'
