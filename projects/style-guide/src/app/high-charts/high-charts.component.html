Setting up dark-mode

We have some custom css available for Highcharts dark-mode. You can use this by adding the class 'hc-dark-mode' to your 'highcharts-chart' component. However, it is preferable to use Highcharts own dark-mode settings as there may be display issues, especially on the more complex charts.

Please visit this the Highcharts website for instructions on setting up dark-mode.
