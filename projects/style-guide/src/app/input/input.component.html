Date-picker

For date-pickers, use the NGB datepicker along with our markup which is styled specifically to match our branding. The date-picker placeholder format should be dd-mon-yyyy and the rendered date format that then appears in the UI should be unhyphenated and capitalized, for example 01 Jan 2021
