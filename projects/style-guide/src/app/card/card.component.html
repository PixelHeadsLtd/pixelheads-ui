Card standard

The standard card can be used as part of an organogram chart or on its own, when solo it's usually used inside the Design Language blade.

Included in the card component below is the context-menu component which can also be found here.

Card mini

The card mini is used for the Organisation app overlay, but can be used in others areas where you might want to display a collection of contacts/details. You can switch to use a profile image or alternatively an icon.
