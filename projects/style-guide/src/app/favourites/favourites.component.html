Favourites - landscape and portrait

We have customisable landscape and portrait versions on our favourites. You will need to choose a background-colour tint from our colour palette

Attributes
Element Attribute Type Default
aa-favourites [showLandscapeFavs] Boolean True
aa-favourites [showPortraitFavs] Boolean True
aa-favourites [disableFavsStar] Boolean False
aa-favourites (anchorClick) Click event See Gist
aa-favourites (favClick) Click event See Gist
aa-favourites favsHeading String Your favourites heading
aa-favourites - array item favColour Class Use one of our background colours
aa-favourites - array item favLabel String Limit to 3 chars, any more will trigger truncation
aa-favourites - array item favTitle String Your title
aa-favourites - array item favTextLineOne String Your first line text
aa-favourites - array item favLineTwo String Your second line text
aa-favourites - array item favTextLineThree String Your third line text

Dashboard favourites

The dashboard-favourites are currently used for Performance Reporting app and in conjuction with the accordion-fancy component.

To use the material icons, set [materialIcons]="true" then update [iconName] with your chosen icon. Finally, set the icon colour with iconColour="aa-mycolour-100"

Attributes
Element Attribute Type Default
aa-dashboard-favourites [isFavourite] Boolean True
aa-dashboard-favourites [materialIcons] Boolean True
aa-dashboard-favourites favIconClass String Your Font Awesome icon & icon colour
aa-dashboard-favourites iconColour (Material icons only) Class Refer here
aa-dashboard-favourites tagName String Your tag names
aa-dashboard-favourites lastViewed Date Your date
aa-dashboard-favourites favDescription String Your description
aa-dashboard-favourites (favClick) Event Your event
aa-dashboard-favourites favouritesTitle String Your title
