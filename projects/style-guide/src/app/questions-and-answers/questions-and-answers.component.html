  • NGB datepicker
  • NG select

What date format should I use for the NGB-datepicker

The format is described here but just to reiterate, the datepicker placeholder format should be dd-mon-yyyy and the rendered date format that then appears in the UI should be unhyphenated and capitalized, for example 01 Jan 2021

Which Design Language components can I use with AG-grid?

You can use some of our components. These include:

  • Buttons
  • Checkboxs
  • Radios
  • Selects
  • Inputs
  • Alert shields
  • Material-icons

If you need to add a specific component that's not listed above, please contact the UX Team and we'll endeavour to create/adapt to display with AG-grid. Please do not use custom background colours as this will not work in dark-mode

Questions about Design Language components

Where can I find the markup for a given component?

Most if not all of our components listed in the left menu from Animations to Widgets have an accompanying gist file that can be accessed by opening the right side View gist blade

Can we use custom css in our projects?

No, please do not use custom css! This is for a very good reason. All of our components have accompanying SASS files that are designed specifically for our Apps to work correctly with Flex and dark-mode. If you really need to tweak things, you can use our collection of helpers/modifiers that are listed under the Modifiers section in the left navigation.
