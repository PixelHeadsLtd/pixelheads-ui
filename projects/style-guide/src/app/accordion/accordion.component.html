Make sure you set a minWidth

If you do not set the correct minWidth, then the text and any other elements nested in the header will wrap.

To get the correct minWidth minimize the screen for mobile and then you'll see how the header content behaves. If it's wrapping, keep increasing the width until corrected.

Drag and drop

To enable drag-and-drop for your accordions, please wrap the ph-accordion inside a div with the class ph-drag-container. On the same div, also add cdkDropList (ckkDropListDropped)="drop($event)"

Finally, add cdkDrap to the ph-accordion itself. See gist for example markup. Note: This implementation is the same for all accordion.
