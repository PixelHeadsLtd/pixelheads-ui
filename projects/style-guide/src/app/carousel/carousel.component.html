Carousel

The Carousel can be used to display any custom content of your choosing. You can also set the max-width and have you items displayed center by setting the alignCenter boolean to true

Attributes
Element Attribute Type Default
aa-carousel customClass Class Choose a background or border colour
aa-carousel carouselOuterWidth Any Set the carousel width
aa-carousel carouselInnerWidth Any Set the carousel inner width
aa-carousel carouselInnerHeight Any Set the carousel inner height
aa-carousel carouselItemWidth Any Set the carousel item width
aa-carousel carouselItemBgColour Any Set the carousel item background or border colour
aa-carousel carouselItemPadding Any Set the carousel padding
aa-carousel nextBtnColour Any Set the next button background or border colour
aa-carousel nextBtnIcon String Choose your next btn icon
aa-carousel prevBtnColour Any Set the previous button background or border colour
aa-carousel prevBtnIcon String Choose your previous btn icon
