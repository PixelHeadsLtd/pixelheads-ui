Filter

The filter can be hidden by default. If this is the case, please use the filter button to toggle the filter. Please remember to place the filter inbetween the 'control-bar' and the 'content-container'. For details, please refer to the Page templates

If you need to add a form to the filter. Make sure the filter sits inside the form and not the form inside the filter. This is so we maintain a responsive layout. Adding a form wrapper inside the filter will break flex

Filter left

Filter left can be useful when we need to display the page in two columns, it also reducuces vertical page scrolling. Place this filter inside your 'content-container' adding the class names 'padding-left-0 flex-group flex-start'. This will push the filter over to the left side so there is no left spacing on the page whilst also setting up your container to display it's contents horizontally using flex. You're right side content will need to be wrapped in some container. You'll need to set the filter to be a lot narrower than your right-side content, to do this use a flex value on each, for example 'flex-1' for the filter and 'flex-5' for the right-side content. See the Flex section for more details.
