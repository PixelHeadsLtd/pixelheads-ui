NGB datepicker

For date-pickers, use the NGB datepicker along with our markup which is styled specifically to match our branding. The date-picker placeholder format should be dd-mon-yyyy and the rendered date format that then appears in the UI should be unhyphenated and capitalized, for example 01 Jan 2021

Installation steps

  1. Install ng-bootstrap with 'ng add @ng-bootstrap/ng-bootstrap'
  2. In your package.json you should now see 'ng-bootstrap/ng-bootstrap' & 'bootstrap'. Remove the bootstrap entry and run npm install
  3. After installing, the 'NgbModule' would have been automatically added to your app.module.ts
  4. In your solution, open the 'styles.scss' file and remove the @import '~bootstrap/scss/bootstrap' entry
  5. Copy the below Gist markup and paste this into your App
  6. Import ng-bootstrap in the associated .ts file NgbAlertModule, NgbDatepickerModule, NgbDateStruct from '@ng-bootstrap/ng-bootstrap'
  7. In the same .ts file, add the model reference model: NgbDateStruct
  8. Continue by adding your date-picker logic
