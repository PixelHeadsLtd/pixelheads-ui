NGB timepicker

A handy timepicker. Alway remember to structure your timepicker in the same way that you would structure a regular field input

Requires "ng-bootstrap". But please ensure you uninstall "bootstrap" if it's present in your project, these are two seperate libraries. The main bootstrap library MUST NEVER be installed as it will break Design Language layout.

See the docs & StackBliz demos
