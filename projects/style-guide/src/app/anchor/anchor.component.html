Anchor

Anchor

Anchor sits inside the control-bar above the h1.

Attributes
Element Attribute Type Default
aa-anchor-back anchorBackText String Previous page title
aa-anchor-back routerLink Path Your path

Anchor advanced

Anchor advanced would be used in your main page content area

Attributes
Element Attribute Type Default
aa-anchor-advanced [routerLink] Route Your router link
aa-anchor-advanced [anchorURL] URL Your anchor url
aa-anchor-advanced width Number 15 is recommended
aa-anchor-advanced icon String Your material-icon name
aa-anchor-advanced title String Your title
aa-anchor-advanced desc String Your description
aa-anchor-advanced contentType String Your content type description
aa-anchor-advanced [lime] Boolean Colours incl: pink, blue, orange, yellow, green and lime
