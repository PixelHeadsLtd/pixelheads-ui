Slider

The slider can be used as an alternative for a standard checkbox.

Inline version

Attributes
Element Attribute Type Default
aa-slider Component N/A N/A
aa-slider sliderInline Boolean false
aa-slider sliderChecked Any checked or not checked
aa-slider labelText Any Your label text
aa-slider fieldClass Class Your custom class
aa-slider sliderId Id Your Id
aa-slider sliderValue Any Your Slider value
