Slider

The slider can be used as an alternative for a standard checkbox.

Inline version

Inline version. Horizontally aligned with labelMinWidth

Attributes
Element Attribute Type Default
ph-slider Component N/A N/A
ph-slider [sliderInline] Boolean false
ph-slider sliderChecked Any checked or not checked
ph-slider labelText Any Your label text
ph-slider labelMinWidth Any Your min width in rem or %
ph-slider fieldClass Class Your custom class
ph-slider sliderId Id Your Id
ph-slider sliderValue Any Your Slider value
ph-slider [lockOnPosition] Boolean True
