Validation

How should validation work in our Apps?

Defaults

All our inputs are mandatory by default unless they are indicated as optional by including the optional class on the given field, refer here for optional tag. With this approach we have a much cleaner screen that's not littered with red messages which can be overwhelming for the user, particularly on screens with heavy data.

Touched, dirty or bad data

A validation message should appear if a given field has been touched or if the field is dirty, in other words a value has been added and then removed for example. Also if bad data has been added, for example an incorrect email format.

Submit

Do not set the submit button to disabled. We have made the decision to always display the submit button whether the form is valid or invalid. You will need to create an onSubmit() function and loop through the fields within the ngOnInit() and display the validation on any invalid fields.
