Header secondary

There is an option available to include a secondary header. The secondary header is fixed, similar to the main page header. This allows the page content to scroll beneath. For this to work correctly in your App there a two things you'll need to do. Firstly, in your app.components.ts file add a HostBinding @HostBinding('attr.id') secondaryHeader = 'show-header-secondary';. Secondly, add the actual html element for the header inside app.component.html with the class name header-secondary. This will pick up the correct css from Design Language and reposition the core anglo-framework left navigation, main content container and any blades used.
