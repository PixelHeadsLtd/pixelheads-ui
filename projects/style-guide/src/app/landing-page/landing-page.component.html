1. What is the Design Language?

The Design Language project was built to provide design styleguides and a component library to be used across ALL applications within Marketing IM. Please do not use any 3rd party components other than those listed in the left navigation under the heading Other widgets

2. Who should use this resource?

Anyone interested in our design standards, but it's mainly intended for developers. If there's something you cannot find or you need assistance, please check the Stack Overflow page or post a question in the Slack 'core-ui' channel

3. Where do I begin?

After you've set up Design Language, you'll be able to use the components listed below. If you need sample markup, please visit the Page layout examples. Do not use Bootstrap, instead we use Flexbox which is a far cleaner approach, easy to use and very effective for responsive layouts

4. How do I use a component in my project?

When you've found the component you want to use, either by browsing the full list below, using the left navigation or Search facility, click on the View gist button to access the markup. You'll also find an Attributes table on all the component pages

We use Flexbox for all our page layouts. We don't use Bootstrap under any circumstances so avoid insalling this. For managing form data please use one of our blades. Your page layout and data will determine the type of blade you should use but as a general rule, table data with multiple columns sits best in the Blade bottom components and basic form data, inputs, selects etc sit best inside the regular Blade. Configure your app files

In your project angular.json call the styles file from the node package.
Ensure the Anglo one is last.

  1.  "styles": [
  2.     "path/to/all/other/scss/files.scss",
  3.     "node_modules/@angloamerican/styles/src/scss/styles.scss"
  4.  ],

In your project app.module.ts import the modules

  1.  import {
  2.     AnimationsModule,
  3.     ElementsModule,
  4.     LayoutModule,
  5.     NavigationModule,
  6.     PatternsModule,
  7.     WidgetsModule
  8.  { from '@angloamerican/components';

and declare them as imports

  1.  imports: [
  2.     AnimationsModule,
  3.     ElementsModule,
  4.     LayoutModule,
  5.     NavigationModule,
  6.     PatternsModule,
  7.     WidgetsModule
  8.  ],

In your project tsconfig.json declare the paths.

  1.  "paths": {
  2.     "@angloamerican/components": [ "node_modules/@angloamerican/components" ],
  3.     "@angloamerican/components/*": [ "node_modules/@angloamerican/components/*" ]
  4.  {

Setup

Create a basic html page with your preferred HTML editor. Set your default font family, weight, line-height and size on the body element:

<body style="font-family: Roboto; font-size: 12px; color: #323232; margin:0; padding:20px; line-height: 17px"></body>

For the construction of the template, use a table inside the body and set the cellpadding to at value of at least 10, as this will help with section spacing.

<table align="center" border="0" cellpadding="10" cellspacing="0" width="600">

You can’t use stylesheets in the conventional manner, instead you have to go back to basics and use inline css on the actual element itself. If you were thinking of using the block at the top of you’re page, don’t, as that won’t work either.

Try and use conventional html tags for aesthetics and layout. For example, use the strong tag for bold text rather than setting a style with font-weight: bold to the element. Likewise, utilise the heading tags h3, h2, h1 etc for small, medium and large headings. For spacing sections in your template, try and use new table rows, that's where the cellpadding you set earlier with come into play, It’s more effective that using margins and padding as these are also ignored by most email clients. For large areas of text, use the paragraph tag as you would normally.

Using images

If you want to use images in your template, you will need to either host them where your recipients have access or embed them in the html template itself. If you choose to embed them (and this is the easiest option) the source image must be a bitmap file such as a PNG, GIF or JPEG you cannot embed vector-based images such as SVG. When your bitmap image is ready, use this tool to generate a data url.

When you’ve generated the data url, copy and paste it to the source of your image tag like so…

<img src=”the dataurl you copied earlier” alt=”your image name” />

Creating grids and charts

Use nested tables for grid layouts. If you want unified columns with spacing, you’ll need to set the width of the first cell.

<table>
   <tbody>
    <tr>
      <td width="150"><strong style="color:#0075b0">Name</strong></td>
      <td>Paul Smith</td>
    </tr>
    <tr>
      <td width="150"><strong style="color:#0075b0">Job Title</strong></td>
      <td>Project Manager</td>
    </tr>
    <tr>
      <td width="150"><strong style="color:#0075b0">Country</strong></td>
     <td>United Kingdom</td>
    </tr>
  </tbody>
</table>

Will produce something like

Name
Paul Smith
Job Title
Project Manager
Country
United Kingdom

Tidy things up in Outlook or other client

When you have the template open in Outlook, it will most likely look a bit different than your browser version. For example, your images might not appear at the correct size, the font you chose will default to Outlooks default font etc. I would suggest at this point, tidy things up as best you can. Select all and reset your font family, drag images to scale to the correct size and modify font sizes until you’re happy, you can also set the email background to a chosen color if required.
