1. Starting a new project?

Design Language is a mandatory resource for building IM Marketing applications. There are a few exceptions where we rely on 3rd party components, these are listed under the 'Third-party components' section found in the left-hand navigation

2. Can't find a suitable component?

If for any reason you cannot find a suitable component for your project, or you need a modification to an existing component. Please reach out to the UX Team or add a request in the Slack 'core-ui' channel

3. Where do I begin?

After you've set up Design Language, you'll be able to use the components listed below. If you need sample markup, please visit the Page templates. Do not use Bootstrap

Bootstrap

If you see bootstrap in your package.json, please uninstall it as it breaks our css. We use 'Flex' for layout and mobile adaption.

The only exception is 'ng-bootstrap' which is allowed

 instead we use Flex which is a far cleaner approach, easy to use and very effective for responsive layouts

4. How do I use a component in my project?

When you've found the component you want to use, either by browsing the full list below, using the left navigation or Search facility, click on the View gist button to access the markup. You'll also find an Attributes table on all the component pages

Animations

Animated loading spinners are available here for your project. We currently have two versions, one for in-line loading whereby other elements such as form submissions are still accessible and a second "page" version that blocks any interactions until the full page has loaded. Be sure to use the correct version.

Elements and Inputs

We have a selection of elements and inputs available including Buttons, Selects, Tables, Checkbox's etc. These have been styled specifically inline with the Anglo American brand guidelines. We try to avoid third party components but there are two exceptions to the rule, these are NG-Select and AG-Grid. However, please only use these if the project requires the features that are available with these particular components. Otherwise, always stick to using native elements.

Layout

We use Flexbox for all our page layouts. We don't use Bootstrap under any circumstances so avoid installing this. For managing form data please use one of our blades. Your page layout and data will determine the type of blade you should use but as a general rule, table data with multiple columns sits best in the Blade bottom component and basic form data, inputs, selects etc sit best inside the regular blade. Blade top is rarely used.

Configure your app files

Add the Design Language Styles

In your project angular.json call the styles file from the node package.
Ensure the Anglo one is last.

  1. "styles": [
  2.     "path/to/all/other/scss/files.scss",
  3.     "node_modules/@angloamerican/styles/src/scss/styles.scss"
  4.  ],

Add the Design Language Components

In your project app.module.ts or shared.module.ts import the modules

  1.  import {
  2.     AnimationsModule,
  3.     ElementsModule,
  4.     LayoutModule,
  5.     NavigationModule,
  6.     PatternsModule,
  7.     WidgetsModule
  8.  } from '@angloamerican/components';

and declare them under @NgModule > imports

  1.  imports: [
  2.     AnimationsModule,
  3.     ElementsModule,
  4.     LayoutModule,
  5.     NavigationModule,
  6.     PatternsModule,
  7.     WidgetsModule
  8.  ],

In your project tsconfig.json declare the Components paths.

  1.  "paths": {
  2.     "@angloamerican/components": [ "node_modules/@angloamerican/components" ],
  3.     "@angloamerican/components/*": [ "node_modules/@angloamerican/components/*" ]
  4.  }
