Summary top

Summary top is a useful widget for displaying key read-only information at the top of your page. For consistency we prefer you to use the default version. Please refer to the Attributes table for all available options

Vertical display

Vertical display (displayBlock="true)"

Attributes
Element Attribute Type Default
ph-summary-top N/A Component N/A
ph-summary-top displayBlock Boolean false
ph-summary-top verticalDisplay Boolean false
ph-summary-top-list [highlight] Boolean False
ph-summary-top-list [divider] Boolean False
ph-summary-top-list itemTitle String Your title
ph-summary-top-list itemDescription String Your Descripton
ph-summary-top-list truncate Boolean False
ph-summary-top-list maxWidth (Only if using truncate) Number Your number

Default (most used)

Block display (blockDisplay="true")
