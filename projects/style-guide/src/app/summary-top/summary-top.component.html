Summary top

Summary top is a useful widget for displaying key information at the top of your page. There is an added feature to highlight a particulr section in order to give it more prominence. Use [highlight]="true" to achieve this.

Attributes
Element Attribute Type Default
aa-summary-top N/A Component N/A
aa-summary-top-list [highlight] Boolean False
aa-summary-top-list itemTitle String Your title
aa-summary-top-list itemDescription String Your Descripton
