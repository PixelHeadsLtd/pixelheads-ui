Tooltip

You can use the tooltip only version alongside any HTML element and/or component. If you want the tooltip to appear to the right of a field label, set [includeLabel]="true" then replace the field label with the tooltip itself as the label is nested inside the component, just add your label text to labelName string.

Attributes
Element Attribute Type Default
aa-tooltip [isInfo] Boolean True/False
aa-tooltip [isWarning] Boolean True/False
aa-tooltip [isError] Boolean True/False
aa-tooltip [isSuccess] Boolean True/False
aa-tooltip zIndex Number 1
aa-tooltip setMinWidth Number 12
aa-tooltip setMaxWidth Number 30
aa-tooltip ypos String top or bottom
aa-tooltip xpos String left or right
aa-tooltip [includeLabel] Boolean False
aa-tooltip [includeLegend] Boolean False
aa-tooltip labelName String Your label text
aa-tooltip customIcon Boolean False
aa-tooltip iconName String Material icon friendly name

Show as an anchor
aa-tooltip [showAsAnchor] Boolean True
aa-tooltip tooltipAnchor Any Your tooltip anchor text
aa-tooltip [preventAnchorWrapping] Boolean N/A

Show as button
aa-tooltip [showAsButton] Boolean True
aa-tooltip xpos, ypos String left top, left bottom, right top, right bottom
aa-tooltip showTooltipOnClick Boalean True
aa-tooltip tooltipBtnText String This is the text you want on your button when the tooltip is displayed
