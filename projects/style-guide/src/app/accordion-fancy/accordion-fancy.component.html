Accordion fancy

The accordion-fancy is currently used for Performance Reporting app and in conjuction with the dashboard-favourites component.

To use the material icons, set [materialIcons]="true" then update [iconName] with your chosen icon. Finally, set the icon colour with iconColour="aa-mycolour-100"
