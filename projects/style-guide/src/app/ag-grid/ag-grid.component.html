Setting the grid height to use all the available space

There are a few important rules that you need to follow for the height setting to work correctly. Please follow the 8 steps below
  1. Ensure the ngStyle height setting is set on the wrapper that encapsulates the entire page. If there's markup outside this wrapper apart from the control-bar, then the page will not be able to calculate the height properly
  2. On this wrapper include the class names grid and ag-grid-full-height
  3. Your ag-grid table MUST be the child element of the page wrapper mentioned above (1) and NOT the ancestor
  4. You must wrap your ag-grid-angular inside a wrapper with the class name ag-grid-wrapper
  5. Make sure the ONLY class names you have on your ag-grid-angular are ag-theme-balham and ag-grid
  6. Make sure your ag-grid-angular with its above wrapper is the last item on your page and below any other content that you might be displaying above the grid
  7. Check the ag-grid TypeScript file to ensure no height is being set. Also, check the project Styles.scss file to make sure no custom css is being applied that sets the height
  8. When your structure is complete, adjust the 9rem value that's set on the aforementioned page wrapper ngStyle, until the browser scrollbars disappear and teh bottom of your grid meets the bottom of the page nicely
