Blade

There are 3 sizes available - please pass the bladeSize value into the component, these are: one-column-width, two-column-width, or xl-column-width

For pinning, set [enablePinning] to true. Then add a conditional [ngStyle] to the content-container. Modify the calculated width depending on the blade size you are using. In the example below, we are setting the width for a one-column-width blade

[ngStyle]=“{‘width’: toggleBlade && pinBlade ? ‘calc(100% - 38rem)’ : ‘ ’ }”

These setting are adjustable.

Attributes
Element Attribute Type Default
aa-blade showModal Boolean false
aa-blade toggleBlade Boolean false
aa-blade bladeSize Class one-column-width
aa-blade topPosition Number 3.5
aa-blade zIndex Number 0
aa-blade enableIcon Boolean false
aa-blade bladeHeading String Your heading
aa-blade enablePinning Boolean false
aa-blade suppressAutoClose Boolean false
aa-blade (bladeOpen) Boolean false
aa-blade (bladePinned) Boolean false

Blade - custom header/footer

If you need to customise the blade header and/or footer please use the below version of the Blade and remember to set [customBlade] to true.

Attributes
Element Attribute Type Default
aa-blade customBlade Boolean false
