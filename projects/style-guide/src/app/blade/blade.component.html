Blade

There are 3 sizes available - please pass the bladeSize value into the component, these are: one-column-width, two-column-width, or xl-column-width

For pinning, set [enablePinning] to true. Then add a conditional [ngStyle] to the content-container. Modify the calculated width depending on the blade size you are using. In the example below, we are setting the width for a one-column-width blade

[ngStyle]=“{‘width’: toggleBlade && pinBlade ? ‘calc(100% - 38rem)’ : ‘ ’ }”

These setting are adjustable.

Attributes
Element Attribute Type Default
ph-blade [blockPageUI] Boolean True
ph-blade [showBladeModal] Boolean True
ph-blade bladeTabs Boolean True
ph-blade toggleBlade Boolean True
ph-blade bladeSize Class one-column-width
ph-blade headingMaxWidth Any Depending on blade size
ph-blade topPosition Any 3.5rem
ph-blade zIndex Number 0
ph-blade [enableIcon] Boolean True
ph-blade iconName String Choose your icon here
ph-blade bladeHeading String Your heading
ph-blade enablePinning Boolean True
ph-blade suppressAutoClose Boolean True
ph-blade (bladeOpen) Boolean True
ph-blade (bladePinned) Boolean True
