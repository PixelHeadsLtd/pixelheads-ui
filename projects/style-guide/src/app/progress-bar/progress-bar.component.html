Progress bar

Will have a nice little progress-bar for you to use in your project.
To use the header version, set [displayOverHeader]="true"

Attributes
Element Attribute Type Default
aa-progress-bar maxWidth Number 10
aa-progress-bar titleBold String Your bold text
aa-progress-bar titleRegular String Your regular text
aa-progress-bar complete Number 0
aa-progress-bar leftSideText String Your left text
aa-progress-bar rightSideText String Your right text
aa-progress-bar progressId Id Your progress Id

Using the full-page header version
aa-progress-bar [displayOverHeader] Boolean True
