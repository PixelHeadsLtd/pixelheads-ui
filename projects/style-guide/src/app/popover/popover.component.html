Popover

Set the [leftPos] to adjust the custom-content popunder position. Set [width] to update the popunder width. Set [hideLabel] to hide label nested inside aa-button. Set [btnSmall] to true if the smaller button is required when nested in a table or ag-grid

Attributes
Element Attribute Type Default
aa-popover btnLabel String Your label text
aa-popover leftPos - to show popover on the left Any 0 (set rightPos to initial)
aa-popover rightPos - to show popover on the right Any 0 (set leftPos to initial)
aa-popover width Any 20rem
aa-popover call-to-action Call to action Your button
aa-popover custom-content Popup content Your content
aa-popover togglePopover() Event this.popOver.close();
aa-popover zIndex Number 10

Show the popover at the top
aa-popover [popoverTop] Boolean True
aa-popover bottomPos Any 3rem
aa-popover arrowPos Any -1rem
aa-popover topPos Any unset
