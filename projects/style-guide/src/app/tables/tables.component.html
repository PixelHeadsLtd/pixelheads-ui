Native table with fixed header

For a scrollable table with a fixed header you will need to nest your table inside two div elements. Add the class .tbl-container to the outer div and .tbl-fixed to the inner div along with an [ngStyle] used to set the rem max-height. Then inside your table thead th cell, add a div with a nested span, inside this span add you cell text.
