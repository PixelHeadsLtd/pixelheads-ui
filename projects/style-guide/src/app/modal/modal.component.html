Modal

Modal - component version

Modals should only be used to inform the user of a particular event and or decision. Please avoid using modals for complex form data/tables etc, for this please use one of the Design language blades.

You can now set different colour themes for the modal. The available colours are: red, orange, green and blue.

If you want to set the modal over aa-blade, please set a rightPos and set lefPos to 'auto'
