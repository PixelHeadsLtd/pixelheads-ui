Overlay

The Overlay component is similar to the Modal only it's designed to accommodate more data including tabbed sections and enriched header content. For tabbed sections, we recommend using the ng-template version.

Attributes
Element Attribute Type Default
aa-overlay [showOverlay] Boolean false
aa-overlay zIndex Number 999
ng-container overlay-header HTML Your header
ng-container overlay-content HTML Your content
