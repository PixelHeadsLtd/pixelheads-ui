Material icons

We use Google's Material icons. There are some legacy Font Awesome icons around, but we are moving towards Material. The easy way to use them is to find one you like and call it by its name in a wrapper element with class 'material-icons' or 'material-icons-outlined'

Country flags

We have a complete set of country flags that you can use. All you need to do is add the class "flag" and the country code class, for example, for Great Britain you would use classes "flag bg"

{{flag}}

Attributes
Element Attribute Type Default
Any Class Class .flag
Any Class Class Your flag class, for example Great Britain is .gb
