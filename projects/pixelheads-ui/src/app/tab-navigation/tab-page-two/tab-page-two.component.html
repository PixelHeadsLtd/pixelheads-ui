Mixing accordions and regular form elements
Custom content

If you would like to use an accordion in your blade. Just add the standard accordion like you would normally. For nested accordions, you will still need the boolean [iconsEnabled] but you won't need to add the iconName or coreIconClass as these are modified in css.

Standard blade

Please refer to the gist file. You have to make sure that the ph-tab-navigation component sits just above the blade-content wrapper. Then ensure that your router-outlet sits inside the blade-content wrapper.

Custom blade

If adding tabs to the custom-blade, you will need to add an ng-container with the select name custom-blade-tabs just inside your custom-header and below your content for the custom-header. Then add your router-outlet inside the custom-content ng-container wrapper. Again please refer to the custom-blade gist file.
