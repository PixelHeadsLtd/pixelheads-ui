Anchor

Anchor

Anchor sits inside the control-bar above the h1.

Attributes
Element Attribute Type Default
ph-anchor-back anchorBackText String Previous page title
ph-anchor-back routerLink Path Your path

Anchor advanced

Anchor advanced would be used in your main page content area

Attributes
Element Attribute Type Default
ph-anchor-advanced [routerLink] Route Your router link
ph-anchor-advanced [anchorURL] URL Your anchor url
ph-anchor-advanced width Number 15 is recommended
ph-anchor-advanced icon String Your material-icon name
ph-anchor-advanced title String Your title
ph-anchor-advanced desc String Your description
ph-anchor-advanced contentType String Your content type description
ph-anchor-advanced [lime] Boolean Colours incl: pink, blue, orange, yellow, green and lime
