Attributes
Element Attribute Type Default
Div [position] String left, right, above and below
Div [phTooltip] HTML Your content, h1, paragraph etc
Div Colour class class Your custom colour class
Div material-icons Icon name Your chosen icon
Div [showDelay] Number 0
Div [hideDelay] Number 1000 (Time given to click a link for example)
Div tooltipWidth Any 10rem
Div tooltipStatus String .info, .success, .pending, .error
