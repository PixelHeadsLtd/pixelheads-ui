Always try to use the component

If you can't use the component, please go here for info on correct form layout

Default

For the button component the visibility of labels are hidden by default. Your button will align nicely with other inputs in your form.

Show a label with [showLabel]=`true`

It's very rare, but there may be occassions where you want to display the button with an additional label. To do this, simple set [showLabel]=`true`

FieldClass boxed

If you have [showLabel]=`true` and you add fieldClass=`boxed`, the button will maintain the label and shift upwards without losing the alignment with other form elements that display a label and have the class `boxed`

If you want to hide the label by setting [showLabel]=`false` and you also want to ensure the correct alignment, then you will need to remove the label on other field elements.
