Feature box - custom border colour

[borderOrange]=true
Attributes

Feature box - mixed content example

As mentioned above, you can add the feature-box class to any element along with any other modifiers. However, we also have a component that allows you to add custom content, either as a single column or two collumn layout as seen in the below example.

{{item.iconName}}

{{item.title}}
{{item.name}}
Attributes
Element Attribute Type Default
ph-feature-box [includeHeader] Boolean True
ph-feature-box [enableScrolling] Boolean True
ph-feature-box fbStatus String .error, .pending, .success
ph-feature-box fbWidth Any Your width in rem or %
ph-feature-box fbHeight Any Your height in rem or %
ph-feature-box marginTop Any Your margin-top in rem
ph-feature-box marginBottom Any Your margin-bottom in rem
ph-feature-box iconName String Your icon name
ph-feature-box fbTitle String Your title
