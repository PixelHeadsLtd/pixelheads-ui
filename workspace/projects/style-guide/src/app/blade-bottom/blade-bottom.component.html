Blade bottom

To get pinning to work, you must add the following to the page content-container
[ngStyle]="isPinned && isOpen {‘'height' : 'calc(50vh - 7.5rem)', 'overflow-y' : 'scroll'}"

These setting are adjustable.

For ag-grid scrolling to fill height, you must set domLayout to 'normal'

Attributes
Element Attribute Type Default
aa-blade-bottom [isOpen] Function Your logic
aa-blade-bottom fullScreenPos Any 7.25rem
aa-blade-bottom unpinnedOffset Any Only set a value, i.e. '4.25rem' if you're using the page footer
aa-blade-bottom [zIndex] Number 1
aa-blade-bottom (bladePinned) Event bladeIsPinned($event)
aa-blade-bottom (bladeOpen) Event bladeIsClosed($event)
