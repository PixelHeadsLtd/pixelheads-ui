Setting the grid height to use all the available space

There are a few important rules that you need to follow for the height setting to work correctly. Please follow the 8 steps below
  1. Ensure the ngStyle height setting is set on the content-container wrapper that encapsulates the entire page. If there's markup outside this wrapper apart from the control-bar and/or filter/tab-navigation, then the page will not be able to calculate the height properly
  2. On the content-container wrapper mentioned above, include the class names grid and ag-grid-full-height
  3. You must wrap your ag-grid-angular inside a wrapper with the class name ag-grid-wrapper
  4. Make sure the ONLY class names you have on your ag-grid-angular are ag-theme-balham and ag-grid
  5. Make sure your ag-grid-angular with its above wrapper is the last item on your page and below any other content that you might be displaying above the grid
  6. If you are displaying other data above the ag-grid-wrapper, make sure this is wrapper in another content-container without the grid class
  7. Check the ag-grid TypeScript file to ensure no height is being set. Also, check the project Styles.scss file to make sure no custom css is being applied that sets the height
  8. When your structure is complete, adjust the 9rem value that's set on the aforementioned page wrapper ngStyle, until the browser scrollbars disappear and the bottom of your grid meets the bottom of the page nicely
